# FoodMunch Static Website

A responsive restaurant landing page built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation, menu filters, demo add buttons, preview interaction, and newsletter form

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Internet is needed for the Google Fonts and remote hero background image.

## Notes
- Menu prices and ratings are sample content for the demo.
- Add buttons and newsletter signup are front-end demonstrations only; no orders or emails are actually sent.
- The page uses a food-preview interaction rather than a hosted product video, so it remains a static site.
